# Coverage Sentinel — 回执索引

`daily-alc-full-coverage-sentinel` 每次运行都会在当日分支 `codex/coverage-sentinel-YYYY-MM-DD` 上提交一份回执，证明**每一份 current 报告**都被复核过（N/N），无论当天是否有报告被编辑。

**本目录按设计不进入 `main`。** 复核人吸收值得合入的内容后，回执随分支一同被清理；这不是流水线故障。分支同时是**双向缓冲**：复核人把裁决写回同一分支的 `YYYY-MM-DD-review.md`，下一次运行先读取并折进记忆，然后才删除该分支。
