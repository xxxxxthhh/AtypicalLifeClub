## 执行摘要

> **框架说明：** 本报告是 AI 基础设施书 demand-risk 层的需求锚。Microsoft 是全球最大的 AI 资本开支买方，但此前本书一直在给 GPU、HBM、电力、光连接的稀缺性打分，却没有覆盖这些开支最终落到的那张资产负债表。核心读数是 **Azure AI 收入 vs 资本开支吸收**：如果 Azure 在 $100B+ 年收入基数上维持 40%+ 增长、同时自由现金流不塌，则 NVIDIA、AMD、Broadcom、SK 海力士、美光、Vertiv、GE Vernova、CoreWeave、Nebius 背后的需求叙事得到全书最强的单点确认；如果 Azure 减速而 capex 继续爬坡，或以 OpenAI 为主的订单簿受损，整条链的稀缺假设都要自上而下重新检验。

**一句话论点：** Microsoft FY2026 Q4（季度截至 2026-06-30，2026-07-29 发布）是本轮周期任何超大规模云厂商交出的最干净的 capex 吸收答卷——收入 $90.0B（+18%）、Azure 及其他云服务 +43% 且持续加速、FY2026 Azure 收入首次突破 $100B、商业 RPO $678B（+84%）、在 $115.9B 现金 capex 之后全年仍有约 $67B 自由现金流——但股价在这条消息上单日重定价 +15.5%，且 2026 年 1 月披露的 RPO 中约 45% 系于单一交易对手 OpenAI。

**当前观点：** **中性观察（neutral-watch）、中确信。** 作为公司，Microsoft 是 demand-risk 层里最好的 capex 吸收者：不同于 Oracle（FY2026 FCF −$23.7B）或 Meta（Q2 2026 FCF $0.78B），它用 $182.9B 经营现金流覆盖了 $115.9B 现金 capex，还向股东返还 $48.7B。作为链上信号，本季财报验证了下游 AI 需求。作为一只 $451.10（2026-07-30 收盘）的股票，市场已经把这份惊喜大半重新资本化：约 25.1x 追溯 GAAP EPS、约 10.1x FY2026 收入、约 49x EV/FY2026 FCF，且在 capex 爬坡延续至 FY2027（Q1 指引超 $50B）期间 FCF 被结构性压制。

## 1. 业务概览

Microsoft 按三个分部报告，而在 FY2026，三个分部的存在意义都指向同一项资产：Azure AI 基础设施建设。财年（截至 2026-06-30）收入 $331.8B，+18%；营业利润 $155.2B——46.8% 的营业利润率在公司历史上最大的 capex 项目中反而扩张了。

| 分部 / 业务线 | FY2026 Q4 读数 | 经济含义 | AI 基建相关性 |
|---------------|----------------|----------|---------------|
| 生产力与业务流程 | Q4 收入 $37.8B，+14% | Microsoft 365、Dynamics、LinkedIn；高毛利年金基本盘 | Copilot 按席位收费是 AI 功能能否定价的主要证据：Microsoft 365 Copilot 付费席位超 3,000 万 |
| 智能云 | Q4 收入 $39.306B，+32%（cc +31%） | Azure、服务器产品、企业服务 | GPU/HBM/电力 capex 的直接落地分部；Azure 及其他云服务 +43% |
| 更多个人计算 | Q4 收入 $12.9B，−4%（cc −5%） | Windows、设备、游戏、搜索广告 | 现金牛，链上相关性有限；唯一收缩的分部 |
| Microsoft Cloud（跨分部口径） | Q4 $59.3B，+27% | Azure + M365 商业版 + LinkedIn 商业 + Dynamics 365 | 衡量商业云规模的最佳单一口径 |
| Azure（财年口径） | FY2026 收入首次超 $100B，+41% | 公司首次披露 Azure 财年破 $100B | 全球最大的单一 AI 收入基数；本书吸收读数的分母 |
| GitHub / 开发者 AI | GitHub Copilot 用户超 5,000 万 | AI 工具链的开发者锁定 | 聊天之外推理需求的领先指标 |

Microsoft 与 demand 层其他标的有两个结构性区别。第一是融资结构：FY2026 经营现金流 $182.935B 覆盖 $115.9B 现金 capex 后还剩约 $67B，AI 建设由经营活动而非债务或股权融资支撑——不同于 Oracle（计划约 $40B 外部融资）或 neocloud。第二是订单簿：商业剩余履约义务（RPO）达 $678B（+84%），约为年收入的 2 倍——是已签约而非期望中的需求。星号在于集中度：2026 年 1 月 Microsoft 曾说明当时 $625B RPO 中约 45% 与 OpenAI 相关，这使一家 AI 实验室成为整个行业最大的一笔信用敏感型积压订单；管理层本季指出，环比 RPO 增长主要来自大型 AI 模型开发商之外的客户。

## 2. 行业与竞争位置

Microsoft 在本书关心的三张地图上竞争。

第一张是超大规模云。Azure +43% 的增速在三大云中基数最大（AI 收入口径）、增速最快，且 FY2027 Q1 指引约 45%（固定汇率）意味着进一步加速。Azure 的优势是分发（企业协议、M365 装机量、混合云存量）加上对前沿模型的优先接入——OpenAI 的负载与模型、对 Anthropic 的股权敞口（本季 $3.2B 未实现收益对应 Anthropic 估值从 $350B 升至 $900B），以及自研模型family。

第二张是 AI 应用变现。Microsoft 365 Copilot 付费席位超 3,000 万、GitHub Copilot 用户超 5,000 万；与 Meta（AI 嵌入广告）或 Google（搜索防御）不同，Microsoft 直接按席位收费，其 AI 收入是 demand 层里最可辨认的。

第三张地图是 AI 基础设施链本身——Microsoft 的 capex 就是需求：

| 链上位置 | Microsoft 的角色 | 对现有覆盖的读数传导 |
|----------|------------------|----------------------|
| GPU / 加速器 | 最大级别的 NVIDIA 外部客户；AMD Instinct 部署；自研 Maia ASIC 项目 | 验证 NVIDIA/AMD 需求；自研芯片替代是商用 GPU 份额的中期风险 |
| HBM / 内存 / 存储 | Azure AI 集群吸收 HBM、DRAM、数据中心 SSD 供给 | 支撑 SK 海力士、美光、SanDisk 的需求读数 |
| 网络 / 光连接 | AI 集群拉动以太网、InfiniBand、光互连量 | 支撑 Arista、Broadcom、Coherent、康宁读数 |
| 电力 / 设施 | 季度含租赁 capex $41B；多 GW 数据中心管线 | 支撑 Constellation、Vistra、GE Vernova、Vertiv、Equinix/DLR 读数 |
| Neocloud | Azure 既与 CoreWeave 类供应商竞争，也（历史上经由 OpenAI 安排）共存 | Azure 加速削弱"超大规模厂商甩卖容量"的熊市论点 |
| 晶圆代工 / 半导体设备 | Maia 与 CPU 项目喂给台积电与设备链 | 对 TSM/半导体设备覆盖的二阶支撑 |

竞争风险真实但目前是二阶的：Google Cloud 与 AWS 的 AI 收入都在增长，Alphabet 季度 capex $44.9B（本中心信号台账 2026-07-22 记录）没有任何退坡迹象；开源与中国模型使模型层商品化，这对 Azure 是双刃剑（输入更便宜，但削弱锚定 1 月 RPO 中 45% 的 OpenAI 护城河）；欧盟对美国超大规模云厂商的主权/监管压力持续。

## 4. 管理层与治理

Satya Nadella 十余年的履历——云转型、OpenAI 合作、动视暴雪整合、如今企业史上最大的私人 capex 项目——是超大规模云厂商中最强的资本配置记录。CFO Amy Hood 的指引纪律本季再次体现：capex 重分类在电话会上被明确解释为会计变更（"除该可用寿命影响外，我们的日历 2026 年 capex 投资预期不变"），这是正确的披露姿态，但投资者此后必须把现金开支与报表 capex 分开跟踪。

治理正面项：常规董事会结构（不同于 Meta 的创始人控制）、持续的股息增长、以及异常详细的云 KPI 披露（Azure 增速、RPO、Copilot 席位）。治理观察项：第一，OpenAI 关系同时是商业合同、类股权利益和战略依赖——1 月披露约 45% RPO 与 OpenAI 相关本身是透明度的进步，但修订后合作的经济条款仍只是部分披露。第二，FY2027 可用寿命延长在工程上说得通（数据中心外壳确实能用几十年），但恰好出现在 AI 建设的折旧浪潮即将压缩利润率的时点；审计师已认可，时点仍值得监测。第三，Microsoft 现在同时持有相互竞争的 AI 实验室（OpenAI 与 Anthropic）的重大权益，随着模型市场整合，这既是信息优势也可能引发利益冲突问题。

## 5. 牛市观点

牛市论点是：Microsoft 是当前世界上唯一在超大规模上证明前沿级 AI capex 能转化为可盈利收入的公司，而市场仍按普通巨型股给它定价。

1. **Azure 在 $100B+ 基数上加速。** 三个季度 +39% → +40% → +43%，且 FY2027 Q1 指引约 45%（cc）。这种规模的软件业务从未这样加速过；它意味着需求仍受供给约束。
2. **吸收是已证明的，不是承诺的。** FY2026 营业利润率扩张到 46.8%，同时现金 capex 几乎是 AI 前运行率的两倍。Oracle 烧现金搞建设；Meta 的 FCF 跌了 91%；Microsoft 仍然产出约 $67B FCF 和 $48.7B 股东回报。
3. **订单簿为爬坡去险。** $678B RPO（+84%）约为收入的 2 倍，且最新环比增长主要来自大型 AI 实验室之外的企业——AI 需求基础正在越过 OpenAI 拓宽的早期证据。
4. **Copilot 是全行业最干净的 AI 变现证明。** 3,000 万+ 付费 M365 Copilot 席位和 5,000 万+ GitHub Copilot 用户是直接按席位计费的 AI 收入——不是广告提升，也不是内部降本。
5. **资产负债表与模型期权。** 约 $36.5B 净现金，加上对 OpenAI 与 Anthropic 双边的股权敞口（后者本季估值从 $350B 升到 $900B），让 Microsoft 无论哪家实验室领先都处于赢面。

上行框架：若 Azure 在 FY2027 维持 40%+、总收入以高双位数复合，FY2027 非 GAAP EPS 有望达到 $20-21；按市场反复给过这家franchise的 28-30x，股价可支撑 $560-630，不需要倍数奇迹。前提是 FCF 在 FY2027 见底、OpenAI 订单簿保持可偿付。

## 6. 熊市观点

熊市论点不是 Azure 弱——而是股价刚刚对一份同时内嵌了本周期最大未解负债的财报完成了重定价。

1. **惊喜已被花掉。** 单日 +15.5% 把股价从约 $390 带到 $451.10；在约 49x EV/FY2026 FCF 上，市场再次把吸收故事资本化，如果下一季 Azure 只是达到抬高后的约 45% 标准，缓冲很薄。
2. **OpenAI 是订单簿内部的单点故障。** 1 月 $625B RPO 中约 45%——约 $280B——依赖一家自身融资需求巨大的未盈利交易对手。OpenAI 的融资挫折、重新谈判或模型市场份额丢失，会把本书最强的需求信号变成最大的减记风险。开源模型商品化直接攻击这一依赖。
3. **FCF 被结构性压制而爬坡仍在继续。** FY2026 FCF（约 $67B）在两年约 20% 利润增长后仍低于 FY2024 水平；FY2027 以一个超 $50B 的 capex 季度开局。若 Azure 增速先于 capex 正常化，FCF 低谷更深，只能靠倍数硬扛。
4. **会计顺风美化未来两年。** 数据中心/办公楼寿命 15→25 年 + 融资租赁转经营租赁，恰在 AI 建设折旧浪潮来临时降低报表折旧与 capex 观感。底层现金开支不变（日历 2026 约 $175B）。FY2027 的利润率扩张将部分来自几何学，市场最终可能予以折价。
5. **竞争压缩奖赏。** Alphabet（季度 capex $44.9B）与 AWS 都没有让出 AI 云份额；Google 的模型栈是第一方的，Azure 的某种程度上不是。若模型接入商品化，Azure 的增长溢价收窄，而它的 capex 承诺不会。

下行框架：按 FY2026 非 GAAP EPS $17.28，若估值回落到 21-23x——即 2026 年 6 月下旬股票实际交易过的倍数——对应约 $365-400。这不是尾部情景；五周前股价就在那里。

- **熊市论点破产：** Azure 在 FY2027 全程维持 ≥40% cc 增长、TTM FCF 在约 $60B 以上见底回升、RPO 继续增长且 OpenAI 占比明显下降。

## 10. 结论

Microsoft 补上了本书最重要的缺口。demand-risk 层的存在意义是检验 AI 基础设施需求是否真实，但它此前缺少吸收这些需求最多的那张资产负债表。以 FY2026 Q4 的证据看，答案目前是肯定的：Azure 在 $100B+ 年基数上加速到 +43%，商业 RPO 达到 $678B，营业利润率在 $115.9B capex 之年扩张，而在 Oracle 处断裂、在 Meta 处弯折的那个指标——自由现金流——守住了约 $67B。

在链的层面，这份财报是本书本周期记录到的最强单点需求确认，且与 Meta 的 $31B capex 季度、Alphabet 的 $44.9B 财报出现在同一周：三家资本最充足的买方都仍在加速。读数传导支撑 GPU、HBM、电力、光连接、设施各层下面的稀缺假设——但保留标准注意事项：指引中的 capex 美元不是任何具体供应商处的采购订单。

在股票层面，纪律更重要。市场正是在这些证据上单日把 MSFT 重定价 +15.5%；$451.10 对应约 26x 清洁追溯盈利与约 49x FY2026 FCF，而 capex 爬坡仍在变陡、1 月订单簿的约 45% 挂在单一交易对手上。经营层面是全层最好的；入场价现在假设它会延续。

初始覆盖立场为**中性观察（neutral-watch）、中确信**。是中而不是高，因为决定论点的两个变量——FY2027 的 Azure vs capex 赛跑和 OpenAI 的财务轨迹——都在当前披露窗口之外。

上调触发：Azure 在 FY2027 维持 ≥40% cc 增长且剔除顺风后营业利润率保持 ≥45%、TTM FCF 在约 $60B 以上见底回升、RPO 继续复合增长且 OpenAI 占比明显下降、FY2027 capex 路径按指引推进且不再上调——上调至偏多（constructive）。下调触发：Azure cc 增速减到 30% 出头或更低而 capex 仍在增长、TTM FCF 跌破约 $50B 且没有声明的 capex 下调路径、OpenAI 信用 / 融资 / 重新谈判事件损害订单簿质量、或需要进一步会计变更来维持利润率观感——下调至谨慎（cautious）。
