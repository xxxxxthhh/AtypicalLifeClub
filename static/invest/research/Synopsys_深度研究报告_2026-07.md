## 1. 业务与链条角色

Synopsys 将芯片设计、验证和可复用 IP 与 Ansys 仿真结合。研究问题是复杂芯片及系统设计能否持续转化为工具使用、可比 IP 销售和现金。单季报告增速不足以拆出 EDA 有机提速，也不足以确认特定客户的定制芯片承诺。

| 链条变量 | 披露证据 | 研究含义 |
| --- | --- | --- |
| Design Automation | Q3 $2.0030B（同比 +53%），前九个月 $5.8266B（+69%） | 同比包含 Ansys 完整期间与上年部分期间的差异 |
| Ansys | Q3 贡献 $622.2M，前九个月约 $2.2B，FY2026 指引约 $2.98B | 并表贡献可见，交叉销售与有机增速需另行核验 |
| Design IP | Q3 $473.8M（+11%），前九个月 $1.3350B 对 $1.3447B（约 −1%） | 收入仍为正值，Processor IP 出售改变了分部构成 |
| 合同未履约义务 | $10.9B，含 $1.9B 不可撤销 FSA。剔除后约 49% 预计 12 个月内确认 | 这是合同义务披露，确认节奏取决于实际执行 |

**ASR 敏感性。** 仅在假设按公告约定扣减约 1.735M 初始股、$1.0B 全部由现金支付，且其余 Q3 资本项目固定时，普通股为 189.870M、市值 $75.220798B、净债务 $7.429691B、EV $82.650489B，对应同一指引中点的 8.51x。该结果仅展示条款的影响。实际股数、现金、融资结构、最终注销和结算仍待申报。主模型用 Q3 披露口径，EV 扣减项排除受限现金，债务项排除经营租赁。

**截至 2028-10-31 的情景网格。** 起点为 FY2026 收入指引中点 $9.715B 和 non-GAAP EPS 中点 $15.07。FY2027–FY2028 为研究情景。净利率指归属于 Synopsys 的 non-GAAP 净利占收入比例。FY2027/FY2028 EPS = 情景收入 × 净利率 / 情景摊薄股数。股权激励、整合费用与摊销会扩大 GAAP 和 non-GAAP 的差异，因此期末市盈率依赖现金转化。表中同一摊薄股数适用于两年模型，最终 ASR 结算另待披露。

| 牛市 | 仿真交叉销售强、可比 IP 改善、经营杠杆释放 | +16% / $11.269B / 32.5% / $19.08 | +14% / $12.847B / 34.0% / $22.75 | 192M / 30x | $682.50 / +32.24% | 20% |
| 基准 | 指引大致兑现，EDA 增长，IP 逐步改善 | +10% / $10.687B / 30.5% / $16.89 | +9% / $11.648B / 31.5% / $19.01 | 193M / 26x | $494.30 / +12.04% | 50% |

以未取整的情景股价乘权重后求和，得加权结果 **$465.41**。持有期为 711 天 / 365.25，约 1.9466 年。年化公式 `($465.41 / $396.17)^(1 / 1.9466) − 1` 得 **8.63%**。主权重给指引基本兑现 50%、可比 IP 强恢复 20%、执行落空 30%。8% 门槛要求期末股价达到 $460.20，按 26x 相当于 FY2028 EPS 至少 **$17.70**，基准情景为 $19.01。加权结果支持达到 8% 门槛的最高入场价约 $400.66。将 5 个百分点从牛市移至熊市得 $444.91、年化 6.14%，反向移动则为 $485.91、年化 11.06%。以上均未计分派。
