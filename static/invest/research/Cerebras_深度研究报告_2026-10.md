## 执行摘要 <!-- report-module:overview -->

**一句话论点：** Cerebras 用晶圆级处理器（WSE）把推理速度做成了可以售卖的差异化，并借 OpenAI 750MW 照付不议合同把自己从“卖整机的芯片公司”变成“自建算力、按容量收费的推理云”；但以 2026-10-16 常规时段收盘 **$127.21** 计，**34.11x EV/TTM GAAP 收入、26.23x EV/FY2026 公司 core 收入指引中点**，价格要求 $25.4B 剩余履约义务（RPO）按期兑现、并在 OpenAI 之外再造一个同等量级的客户群，而公司仍在烧钱、仍有重大内控缺陷、仍在经历分批解禁。

**当前立场：谨慎（cautious）／低确信。** 三年牛市／基准／熊市权重 20%／50%／30%，2029-10-19 情景每股值 $289.67／$121.57／$25.70；加权终值 $126.43，折合年化 **-0.20%**，低于本报告 10% 风险调整门槛与 8% 参照。逐档年化收益率的概率加权为 **-6.83%**。退出倍数 +1x、收入 +20% 或权重改为 30／50／20 的单项有利敏感性分别为 +5.52%／+5.50%／+6.30%，均未过门槛。确信度为低，因为公司上市后只有两个季度公开报表、首份上市后 10-K 尚未出具、RPO 高度集中在一个可因交付失约而部分终止的合同上，分布两端都很厚：牛市 +127.7%、熊市 -79.8%。

**关键催化与窗口：** 2026-10-28 一批约 19.4M 股解禁；全部锁定于 Q3 业绩后第二个交易日或 2026-11-09（取较早者）结束；Q3 业绩日期截至报告日**未公布**。之后 6—18 个月检验 Q4 core 毛利率回升、OpenAI 容量分批交付、AWS Bedrock（Q2 业绩稿称 2027 Q1）及其他超大规模云（Q2 电话会称 2027 年中首笔收入）。研究角色为 compute 层的**架构校验**：检验 SRAM 晶圆级推理能否在 GPU／HBM 主导的计算层获得独立、可持续、非单一客户的采用。

## 1. 业务概览与分部经济 <!-- report-module:business -->

Cerebras 是 fabless 计算公司：TSMC 5nm 代工整片晶圆，ASE 做再布线层，最终晶圆封装、组装和测试在 Sunnyvale 完成。核心是 WSE-3——单片 46,225mm² 硅、4 万亿晶体管、90 万核、44GB 片上 SRAM、21PB/s 片上带宽。它不依赖 HBM 和 CoWoS，公司把这点当成供给优势。经济上，公司过去主要卖 CS-2／CS-3 整机给少数大客户；2026 年起，收入重心转向自建或租赁数据中心、以“专用容量（Dedicated Capacity，照付不议）”和“按需 token”方式出售推理服务。[424B4 Business](https://www.sec.gov/Archives/edgar/data/2021728/000162828026035214/cerebras-424b4.htm)

## 2. 行业、竞争与架构校验 <!-- report-module:competition -->

AI 推理计算并不是一个单一市场。GPU（Nvidia、AMD）以 HBM＋高带宽互连做通用吞吐；定制 ASIC（Broadcom／Google TPU、AWS Trainium）以平台锁定换成本；Cerebras 用片上 SRAM 换单流 token 速度，主打低延迟、长输出的推理（代码代理、实时语音、推理模型的“快速模式”）。速度溢价是否值钱，取决于终端应用是否愿意为更低延迟付费、并且能否在 GPU 与 ASIC 的成本曲线下降时保持差距。

| 比较维度 | CBRS | GPU 平台（NVDA／AMD） | Neocloud（CRWV／NBIS） | 对投资判断的约束 |
|---|---|---|---|---|
| 核心差异 | 晶圆级 SRAM，单流速度；不依赖 HBM／CoWoS | 通用生态、CUDA／ROCm、HBM 带宽与规模 | 采购 GPU 出租，赚资本与运维价差 | CBRS 同时是芯片公司和云运营商，需要两种护城河 |
| 收入模式 | 2026 年起云服务为主，硬件为辅 | 卖芯片／系统，高毛利 | 租赁合同、长期 backlog | CBRS 的毛利率目标 60%+ 介于两者之间，需证明 |
| 最新季度毛利 | GAAP 14.2%／core 40.6% | 远高于 CBRS（本报告未逐项重算） | 资产重、折旧主导 | core 毛利率仍低于公司长期目标约 20 个百分点 |
| 客户结构 | MBZUAI＋G42 合计 43%、OpenAI 约 31.5%（Q2） | 广泛 | 也高度集中于少数 AI 实验室 | 集中度与 neocloud 相近，不是芯片商常态 |

| 其他 SRAM／推理芯片初创 | 类似低延迟定位、更便宜 | 公司未披露份额；只能用新签约与价格读数间接检验 |

可观察的护城河是：整片晶圆的良率与封装工艺、编译器与推理软件栈、已签约的 600MW 以上数据中心容量（公司称截至 2027 年底上线或签约），以及进入 OpenAI 与 AWS 的客户背书。无法核实的是：独立市场份额、同等延迟下的单位 token 成本对比、各客户的定价。链条上本报告把它定为**架构校验**而不是“需求仪表盘”：它检验非 GPU 架构能否以独立客户群存活，而不是检验 AI 资本开支总量。

## 5. 牛市观点 <!-- report-module:bullBear -->

**第一，已签合同给了芯片初创公司罕见的收入可见性。** $25.4B RPO 是 FY2026 core 收入指引中点的约 29 倍；其中约 $5.6B 在 2028 年中以前、约 $10.9B 在之后两年确认。OpenAI 承诺容量为照付不议，公司称已有 600MW 以上数据中心容量上线或签约。若交付按期，2028—2030 年仅现有 RPO 就对应每年约 $5B 级别的收入，远高于今天 TTM $0.68B。

**第二，速度差异有真实客户在付费。** OpenAI GPT-5.6 Sol 的“Ultrafast”模式由 Cerebras 提供（[Q2 业绩公告](https://www.sec.gov/Archives/edgar/data/2021728/000162828026056186/cbrsannouncesfinancialresu.htm)称其为 GPT-5.6 Sol 首发合作方并支持 750 tokens/s，2026-08-13 公司公告另述；第 2 节所述该类负载转向 Nvidia 的媒体报道未证实，本报告不采信也不排除），Cognition、Lovable、CrowdStrike 等以低延迟为卖点签约；AWS 选择 Trainium3＋CS-3 组合，说明超大规模云愿意在自家芯片之外引入 WSE 做解码。推理占 AI 计算比重上升、代码代理与推理模型的输出更长，单流速度的经济价值可能被低估。

**第三，经营杠杆已有方向性证据，资产负债表能支撑扩张。** Q2 core 收入 $209.9M 大幅高于 $194M 指引，core 经营利润率 -16% 好于 -30%—-32% 指引；CFO 称 Q3 是 core 毛利率低点、Q4 起随自有系统占比上升而“显著改善”，长期目标 60%+。$7.9B 不受限现金投资、$850M 未提用循环信贷、不依赖 HBM／CoWoS 的供应链，使公司在交付窗口内不必依赖资本市场。

牛市 FY2030E core 收入 $13.0B（自 FY2026 指引中点四年 CAGR 95.8%）：OpenAI 行使部分 1.25GW 选择权、AWS 及另一家超大规模云在 2027—2028 年放量、CS-4／CS-5 硬件外售恢复。退出 7x EV/前瞻收入、调整净现金 $2.853B、股数 324M（含全部 OpenAI 未归属权证与首档 PRSU），2029 年每股 $289.67，较 $127.21 +127.7%。它需要交付、扩客与倍数同时成立，故权重 20%。

## 6. 熊市观点 <!-- report-module:bullBear -->

**第一，最大的资产也是最大的单点风险。** OpenAI 可因容量未按时交付或 SLA 失败而部分或全部终止 MRA，终止时 $918M 贷款到期；合同还有排他条款，限制公司服务 OpenAI 的指定竞争对手。媒体已报道 OpenAI 某快速推理负载转向 Nvidia——本报告视为未证实，但它说明买方有替代选择、也有议价能力。若 OpenAI 只按最低承诺执行或推迟分批，RPO 的时间表会后移，而公司已签的长期租约不会随之后移。

**第二，商业模式正在变重，回报率尚未被证明。** 从卖整机转向自持云，意味着 capex、数据中心租约、电力成本与利用率风险全部由公司承担；TTM FCF -$680M，Q2 core 毛利率 40.6% 仍远低于 60% 目标。权证摊销会持续冲减 GAAP 收入至 2031 年，代收代付会稀释毛利率。即使收入兑现，股东可得现金也可能长期低于收入增长暗示的水平。

**第三，供给面的股份压力尚未结束。** 10-28 还有约 19.4M 股解禁，最终全部释放不晚于 11-09；完全稀释代理约 313.6M，较已发行多约 76M 股；SBC 将显著上升；风投正在实物派发，内部人持续卖出。三类股结构和分期董事会意味着外部股东难以通过治理约束资本配置。

**第四，业务即使增长，估值也可能大幅压缩。** 熊市 FY2030E core 收入 $3.0B，仍是 FY2026 指引中点的 3.4 倍、并非假设业务消失；但若 OpenAI 部分终止或不续约、AWS 与新客户放量慢、存量数据中心形成闲置，退出 1.5x EV/前瞻收入（资产重、利用率不足的托管业务）、调整净现金 $3.363B、股数 306M，每股 $25.70，较现价 -79.8%。给熊市 30% 而非更低，是因为客户集中、交付终止权、内控缺陷与股份供给都已是披露事实，而非想象。

## 10. 结论 <!-- report-module:conclusion -->

CBRS 的链条任务是检验：在 GPU／HBM 与超大规模云 ASIC 主导的计算层里，一个非 GPU 架构能否凭推理速度获得独立、可持续且不依赖单一客户的采用。到 Q2 2026，答案是“已获得大客户采用，但还不独立”：收入的约四分之三来自 OpenAI 与互为关联方的 MBZUAI／G42，第二个超大规模客户尚未起租。

预期差在于价格要求：基准 4.5x 退出下，保持现价需要 FY2030E core 收入 $7.89B，获得 10% 年化需要 $10.80B；本报告基准 $7.5B 已假设 OpenAI 750MW 全额按期交付，并再加约 $3B 的新客户收入，仍只得到 -1.50% 的年化。股价从首日 $311.07 跌到 $127.21，把一部分风险定价了，但没有给出足够的安全边际。

因此立场为**谨慎／低确信**：20%／50%／30% 网格加权终值 $126.43、年化 -0.20%，低于 10% 门槛；单项有利敏感性最高 +6.30%，仍低于门槛；熊市在收入仍增长 3 倍多的情况下仍可造成 -79.8% 的损失。保留技术与合同上行的可能，拒绝把“合同金额大”与“股东回报足”混为一谈。

**升级触发：** 在情景不变时常规收盘不高于 $94，复核上调至 neutral-watch；或以下三项同时成立后重建情景、只有重算年化达到 10% 才上调：FY2026 core 收入不低于 $885M 且 Q4 core 毛利率不低于 45%；新增非 OpenAI、非 UAE 客户的具名合同使 RPO 增加至少 $3B（以公司公告的合同金额或同期 RPO 增量为准）；首份 10-K 未再报告重大内控缺陷。**降级触发：** 以下任一成立则复核下调至 bearish-avoid：OpenAI 部分终止或下调承诺容量、或 RPO 低于 $24.0B；Q3 core 收入低于 $214M；连续两季 FCF 差于 -$1.0B 且无新签 RPO 支撑；完全稀释代理超过 330M。所有触发均要求使用对应官方申报与完整估值重算；媒体报道与营销公告不算兑现。
